Инструкция по работе с сервисом

Сервис автоматически распознаёт документы через OCR и LLM и раскладывает файлы по папкам клиентов.

Индикатор очереди

В правом верхнем углу главной страницы отображается индикатор состояния сервиса:

  • Зелёный, «0» — сервис свободен, все документы обработаны.
  • Красный с числом — столько документов сейчас находится в очереди обработки.

Индикатор обновляется автоматически каждые 4 секунды.

Разбить и обработать PDF

Используйте, когда у вас есть один большой PDF с документами нескольких клиентов.

  1. Нажмите «Разбить и обработать PDF» на главной странице
  2. Загрузите PDF-файл (перетащите или нажмите «выберите файл»)
  3. Все страницы появятся в виде миниатюр
  4. Если есть лишние страницы (обложки, пустые) — выберите их и нажмите «Удалить выбранные» до следующего шага
  5. Кликните на страницы, с которых начинается каждый новый документ — они выделятся галочкой.
    Пример: стр. 1 — Иванов, стр. 5 — Петров → выбираете стр. 1 и 5
  6. Нажмите «Разделить и обработать» — можно закрыть страницу, сервис работает в фоне
Удерживайте миниатюру (~0,5 сек), чтобы просмотреть страницу в увеличенном виде.

Авто-сортировка файлов

После того как файлы переименованы в правильный формат, их можно одним нажатием отправить в папки клиентов через кнопку «Авто-сортировка».

Формат имени файла: Орг | Фамилия Имя Отчество | А73-12345-2026.pdf

Разделитель — символ | с пробелами вокруг. Все три части обязательны.

Папка «Без номера дела»: нажмите «Авто-сортировка» — сервис сам найдёт все файлы в правильном формате и переместит их в папки клиентов.

Папка «Неизвестные номера дела»: выберите нужные файлы (или все сразу) прямо в интерфейсе, затем нажмите «Авто-сортировка» — переместятся только выбранные.

Файлы перемещаются: исчезают из исходной папки и появляются в папке клиента.

Поиск клиентов и обновление данных

Раздел «Данные по клиентам» решает две задачи:

Обновление базы клиентов: нажмите «Обновить данные» — сервис загрузит актуальный список из файла на Google Диске. Рекомендуется делать это перед началом загрузки новых документов.

Обновление доступно только когда сервис не обрабатывает документы — индикатор показывает «0» зелёным.

Поиск клиента: введите в строку поиска часть ФИО (например, «Иван») или номер дела («А73-1234-2026») — результаты появятся мгновенно. Используйте поиск, когда нужно уточнить правильный номер дела или ФИО перед переименованием файла.

Куда попадают файлы

Успешно распознанные файлы раскладываются по структуре:

Корневая папка / Год / Фамилия Имя Отчество А73-XXXXX-ГГГГ / Ответы /

Если распознать не удалось, файл попадает в одну из двух папок:

  • «Без номера дела» — номер дела не найден в тексте документа. Причины: нечёткий скан, документ не содержит номера, OCR не смог прочитать.
  • «Неизвестные номера дела» — номер найден, но отсутствует в базе Банкротконсалт. Причины: дело ещё не внесено, опечатка в номере, нестандартный формат.

Корректировка файлов

Раздел «Корректировка файлов» — для ручной работы с нераспознанными документами.

  1. Выберите папку: «Без номера дела» или «Неизвестные номера дела»
  2. Кликните на файл — он откроется в просмотрщике справа
  3. Заполните поля: организация, ФИО, номер дела (при необходимости воспользуйтесь поиском клиентов)
  4. Нажмите «Сохранить» — файл переименуется автоматически
  5. Затем нажмите «Авто-сортировка», чтобы переместить файл в папку клиента
Если имя файла уже содержит данные в формате «Орг | ФИО | Дело», поля заполнятся автоматически.

Если файл больше не нужен — нажмите значок корзины 🗑 напротив него для удаления.
