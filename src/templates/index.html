Инструкция по работе с сервисом

Сервис автоматически распознаёт документы о банкротстве и раскладывает файлы по папкам клиентов.

Режим 1 — Разбить и обработать PDF

Используйте, когда у вас есть один большой PDF с несколькими документами разных клиентов.

  1. Нажмите «Разбить и обработать PDF» на главной странице
  2. Загрузите PDF-файл (перетащите или нажмите «выберите файл»)
  3. Перед вами появятся все страницы документа в виде миниатюр
  4. Кликните на те страницы, с которых начинается каждый новый документ — они выделятся галочкой. Например: стр. 1 — Иванов, стр. 5 — Петров → выбираете стр. 1 и 5
  5. Нажмите «Разделить и обработать»
Сервис автоматически распознает ФИО, номер дела и разложит файлы по папкам. Ждать не нужно — можно закрыть страницу.

Просмотр страницы крупнее: удерживайте нажатие на миниатюру (~0,5 сек) — откроется увеличенный вид.

Лишние страницы (обложки, пустые) можно выбрать и нажать «Удалить выбранные» перед обработкой.

Режим 2 — Загрузить готовые файлы

Используйте, когда файлы уже переименованы вручную. Файл должен называться точно так:

Орг | Фамилия Имя Отчество | А73-12345-2026.pdf

Пример: ФНС | Иванов Иван Иванович | А73-19762-2024.pdf

Разделитель — символ | (вертикальная черта) с пробелами вокруг. Все три части обязательны.

Вкладка «Загрузить с компьютера»

  1. Перетащите файлы в область или нажмите «Выберите» (можно выбрать несколько через Ctrl+клик)
  2. Нажмите «Загрузить и разложить»
  3. Сервис проверит формат имени и разложит файлы по папкам клиентов

Вкладка «Сканировать папки сервера» — лучший способ, если файлы уже на сетевом диске

  1. Откройте папку «Без номера дела» через сетевой диск
  2. Переименуйте там нужные файлы, дав им правильный формат
  3. Нажмите «Найти и переместить переименованные файлы»
При сканировании файлы перемещаются (исчезают из «Без номера дела» и появляются в папке клиента). При загрузке с компьютера — оригинал на вашем компьютере остаётся.

Куда попадают файлы

Все файлы раскладываются по такой структуре:

Корневая папка / Год / Фамилия Имя Отчество А73-XXXXX-ГГГГ / Ответы /

Пример: scan / 2024 / Иванов Иван Иванович А73-19762-2024 / Ответы / ФНС | Иванов Иван Иванович | А73-19762-2024.pdf

Что делать, если файл не распознан

Если сервис не смог определить данные, файл попадает в одну из служебных папок:

  • «Без номера дела» — номер дела не найден в документе
  • «Неизвестные номера дела» — номер есть, но не значится в базе Банкротконсалт

Дальнейшие действия:

  1. Откройте нужную папку через сетевой диск
  2. Посмотрите файл и определите правильные данные
  3. Переименуйте файл: Орг | ФИО | А73-12345-2026.pdf
  4. Перейдите в «Загрузить готовые файлы» → вкладка «Сканировать папки сервера» → нажмите кнопку
